## ✨ Overview

AI Personal Assistant Chatbot is an intelligent local assistant developed using **Ollama** and **GGUF models**.

The assistant runs directly on the user's system without requiring cloud inference, providing fast responses, privacy, and customizable AI interactions.

It is designed to simulate a real personal AI assistant capable of answering questions, assisting productivity, and enabling local AI experiences.

## ⚙️ Installation

### Clone Repository

```bash
git clone YOUR_REPOSITORY_URL
```

Open Project:

```bash
cd AI_Personal_Assistant
```

Install Requirements:

```bash
pip install -r requirements.txt
```

Start Ollama:

```bash
ollama serve
```

Run Model:

```bash
ollama run MODEL_NAME
```

Start Application:

```bash
streamlit run app.py
```
